## Цель

Научиться находить элементы в DOM, менять содержимое, атрибуты и классы, добавлять и удалять элементы, а также сохранять состояние страницы между перезагрузками через localStorage.

## Что умеет страница

Блок «Моя коллекция» (секция `#collection`):

- **Добавить гаджет** — создаёт карточку с названием и списком характеристик (вводятся через запятую).
- **Удалить** на карточке — удаляет конкретный гаджет.
- **Удалить последний** — убирает последнюю карточку.
- **Скрыть / Показать список** — переключает класс `.is-hidden`.
- **Светлая / Тёмная тема** — переключает класс `.theme-light` у `<body>`.
- Счётчик под кнопками пересчитывает карточки и характеристики после каждого действия.

Всё работает без перезагрузки страницы. После обновления (F5) список, тема и состояние «скрыт/показан» восстанавливаются.

## Поиск элементов

| Метод | Где используется |
| --- | --- |
| `getElementById` | функция `getElement(id)` — через неё ищутся все кнопки, поля и контейнер |
| `querySelector` | `#collection .form-error` для сообщения об ошибке, `#gadget-list` для обработчика кликов |
| `querySelectorAll` | `#gadget-list .gadget` и `#gadget-list .gadget ul li` для счётчика |

## Манипуляции с DOM

- `createElement` + `appendChild` — сборка карточки: `<li class="gadget">` с `<h3>`, `<ul>` характеристик и кнопкой удаления.
- `textContent` — названия, характеристики, текст кнопок и счётчика.
- `setAttribute` — `data-index` у карточки и кнопки, `aria-expanded` у кнопки скрытия.
- `classList.add/remove/contains` — тема и скрытие списка.
- `splice` и `pop` для массива данных, затем полная перерисовка списка.

Удаление карточек работает через делегирование: обработчик висит на `#gadget-list`, а `event.target.closest('.btn-remove')` определяет, что кликнули именно по кнопке. Поэтому новые карточки не требуют отдельных обработчиков.

## Обработка ошибок

- `getElement(id)` возвращает `null` и пишет `console.error`, если элемента нет в разметке. Все вызывающие функции это проверяют.
- Пустое название или пустые характеристики — сообщение под полями, фокус возвращается в проблемное поле.
- «Удалить последний» при пустом списке выводит «Удалять нечего: список пуст».
- Некорректный `data-index` отсекается проверкой `isNaN(index) || index < 0 || index >= gadgets.length`.
- Чтение и запись localStorage обёрнуты в `try/catch`: хранилище может быть недоступно в приватном режиме, а JSON — повреждён. Если в ключе лежит не массив, берётся список по умолчанию.

## localStorage

| Ключ | Что хранит |
| --- | --- |
| `lab5.gadgets` | массив объектов `{ name, specs: [] }` |
| `lab5.theme` | `"dark"` или `"light"` |
| `lab5.listHidden` | `true` / `false` — скрыт ли список |

Сохранение происходит при каждом изменении, восстановление — в функции `init()` по событию `DOMContentLoaded`. При первом открытии (хранилище пустое) показываются два гаджета по умолчанию.

## Проверка работы

1. Открыть страницу, добавить гаджет, нажать F5 — карточка на месте.
2. Переключить тему, нажать F5 — тема сохранилась.
3. Скрыть список, нажать F5 — список остался скрытым.
4. DevTools → Application → Local Storage — видны три ключа.
5. Очистить хранилище (`localStorage.clear()` в консоли) и обновить страницу — вернётся список по умолчанию.
